# Algolia Demo Frontend — Vanilla JavaScript

A framework-free product-search demo built with [Algolia InstantSearch.js](https://www.algolia.com/doc/guides/building-search-ui/what-is-instantsearch/js/) and Vite. It includes autocomplete, a product-results page, and an expandable horizontal brand refinement list.

## Run locally

Install dependencies and start the Vite development server:

```sh
npm install
npm start
```

Open the URL printed by Vite (normally `http://127.0.0.1:5173`). The InstantSearch page is available at `/instantsearch.html`.

## Build

```sh
npm run build
```
